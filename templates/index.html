01. Sobre Mim

Minha jornada na tecnologia começou na linha de frente do suporte técnico para ERPs. Essa vivência me deu uma compreensão profunda sobre como os usuários interagem com sistemas complexos e quais são os reais pontos de dor nos processos de negócio.

Hoje, utilizo essa experiência atuando como desenvolvedor focado na criação de soluções inteligentes. Minha especialidade é construir aplicações full-stack resilientes, combinando back-end sólido (Python, PHP, PostgreSQL) com interfaces modernas e reativas (TypeScript, Tailwind).

Engenheiro de Software Atualmente

SisOpERP

  • Liderando a migração crítica de um sistema ERP legado (VBA/Access) para um ecossistema 100% web moderno e automatizado, visando a expansão nacional da empresa.

SisOp Site & Web

Monorepo / TypeScript / PHP

O ecossistema SisOp é o projeto principal da SisOpERP, empresa onde atuo. Trata-se da evolução de um sistema legado robusto para a era web moderna.

O SisOpSite funciona como um ambiente de vendas (landing page) de alto nível, criado do zero com design moderno para explicar as soluções ERP para diversos setores da indústria e comércio.

A arquitetura em monorepo garante que o site institucional e o ERP Web compartilhem padrões de código e tipagem via TypeScript, otimizando a manutenção e a escalabilidade da plataforma corporativa.

Barbearia App (SaaS)

Python / Flask / PostgreSQL

Um sistema SaaS (Software as a Service) desenhado especificamente para a gestão de barbearias e salões, com foco em simplicidade para o barbeiro e organização financeira.

  • Painel administrativo completo com dashboard de métricas.
  • Controle de agendamentos e agenda de profissionais.
  • Gestão financeira, controle de caixa e serviços prestados.
  • Desenvolvido com Python (Flask) no backend e banco relacional robusto (PostgreSQL).

Projeto E-commerce

HTML / TypeScript / JavaScript

Interface rica desenvolvida para simular a experiência completa de um e-commerce moderno, focando fortemente na usabilidade (UX) e performance do frontend.

O projeto explora conceitos avançados de manipulação do DOM e gerenciamento de estado no lado do cliente utilizando TypeScript puro, garantindo uma base de código livre de bugs de tipagem.

Implementa carrinho de compras dinâmico, cálculos em tempo real e estrutura pronta para integração com APIs de pagamento e catálogos dinâmicos via backend.
