# Decisões técnicas (ADRs)

Cada decisão relevante vira um registro numerado. **ADR aceito não se reescreve**: se a decisão mudar, crie outro que o substitui e marque o antigo como "substituído por".

## Formato

```markdown
# ADR NNNN: título

- Status: proposto | aceito | substituído por NNNN
- Data: AAAA-MM-DD

## Contexto
## Decisão
## Consequências
```
